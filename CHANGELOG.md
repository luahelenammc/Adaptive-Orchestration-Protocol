# Changelog

## 6.5 — 2026-11-21

- Add function-based phase placement, intent-preserving handoffs, decision-bearing receipts and proportionate independent review. Preserve competent roots and human authority.

This changelog follows the AOP lineage across its former Chat–Work identity. Repository promotion does not reset semantic versioning. Source commits remain in the original repository and are linked below; this repository begins with an honest snapshot rather than rewritten Git history.

## 2026-11-20 — Independent repository promotion · AOP 6.4

- Established this repository as the sole semantic, versioning, adapter, package and release source for AOP.
- Transplanted the current AOP 6.4 body and four adapters from Moon Source commit [`6ec5d7910b561b392b114a1c7b64695a41e4716a`](https://github.com/luahelenammc/Moon-Source/commit/6ec5d7910b561b392b114a1c7b64695a41e4716a).
- Retained the existing protocol family and adapter versions: Astra 2.1, GPT-6 Sol/Luna 2.1, GPT-6.1 Terra 1.1 and Grok Bot 1.0. The repository move does not create a semantic release or reset versioning.
- Corrected stale identity/version metadata and made canonical links resolve to this repository. No routing doctrine was rewritten.
- Added deterministic composite and skill package builds, validation, and a compatibility procedure for Moon Source and the LUAHELENA site.
- Snapshot file hashes and legacy path behavior are recorded in [Migration and Compatibility](docs/MIGRATION_AND_COMPATIBILITY.md).

## 2026-09-24 — Chat–Work 6.1 · surface-neutral control-root routing

- Made the current competent control root the continuity default, separated control surface/root from execution harness and root model, and made surface switching conditional on a material capability, locality, permission, verification or preference reason.
- Preserved the named Chat → Work/Codex → Chat loop while enabling competent compatible roots to execute, delegate, converge and close without a ritual return to Chat.
- Source history: [6.1 semantic release commit](https://github.com/luahelenammc/Moon-Source/commit/38b42f2417614cf9f48d8e5286abf06383f776e1).
